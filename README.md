# مغامرة القطار المغناطيسي

مغامرة تعليمية بزاوية 360° لتلاميذ المرحلة الابتدائية عن أقطاب المغناطيس: التجاذب والتنافر.

**الرابط:** https://alozy666.github.io/magnet-ar/

## القصة
1. يدخل الطفل من بوابة مدينة الملاهي.
2. يستقبله المهرّج «سُكَّر» بحركات بهلوانية ويعطيه غزل البنات.
3. في خيمة السيرك تُريه «المرآة السحرية» قطار الملاهي وهو يتفكك.
4. يضغط على قبعة الساحر فينتقل إلى السكة.
5. يركّب ثلاث عربات باختيار القطب المختلف (تجاذب)، ثم يوقف القطار قبل الجدار باختيار القطب المشابه (تنافر).

تعمل على الحاسوب والسبورة الذكية والآيباد والجوال، وفيها وضع VR. تحتاج اتصالًا بالإنترنت.

## الملفات

- `assets/models.js`: المجسمات والملصقات.
